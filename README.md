# DSS Agrícola — Sistema de Apoio à Decisão para Previsão da Produção de Cana-de-Açúcar

## Sobre o projeto

O **DSS Agrícola** é um projeto de pesquisa científica desenvolvido por estudantes do Ensino Médio do Colégio Militar do Rio de Janeiro, com foco na aplicação de Ciência de Dados e Inteligência Artificial à previsão da produção brasileira de cana-de-açúcar.

A pesquisa busca desenvolver um Sistema de Apoio à Decisão capaz de integrar dados históricos de produção agrícola e variáveis climáticas, contribuindo para a análise de informações relevantes ao planejamento agrícola e energético.

## Objetivos

- Analisar a evolução histórica da produção brasileira de cana-de-açúcar.
- Investigar a influência de variáveis climáticas na produção agrícola.
- Desenvolver e avaliar modelos de previsão utilizando técnicas de aprendizado de máquina.
- Construir uma aplicação web para visualização de dados, indicadores e previsões.
- Promover a transparência e a reprodutibilidade dos experimentos científicos.

## Metodologia

A pesquisa está organizada em cinco etapas:

1. Revisão e mapeamento sistemático da literatura científica.
2. Coleta, organização e tratamento dos dados agrícolas e climáticos.
3. Desenvolvimento e avaliação de modelos preditivos.
4. Implementação do Sistema de Apoio à Decisão.
5. Testes, validação e documentação dos resultados.

## Tecnologias e fontes de dados

As tecnologias e fontes de dados utilizadas ou previstas incluem:

- **Python e Google Colab:** análise exploratória e experimentos preditivos.
- **Pandas e Scikit-learn:** tratamento dos dados e modelagem.
- **FAOSTAT:** dados históricos de produção agrícola.
- **NASA POWER:** dados meteorológicos para integração futura.
- **Streamlit:** desenvolvimento da aplicação web definitiva.
- **Render:** hospedagem do sistema.

## Resultados preliminares

Até o momento, foram realizados:

- Mapeamento sistemático de 15 artigos científicos.
- Análise exploratória da produção brasileira de cana-de-açúcar entre 2015 e 2024.
- Experimentos iniciais com modelos de persistência e Regressão Linear.
- Desenvolvimento de um protótipo funcional de dashboard utilizando Google Apps Script e Google Planilhas.

Os resultados experimentais são preliminares e serão ampliados com novas observações, variáveis climáticas e algoritmos preditivos.

## Reprodutibilidade

Este repositório será utilizado para disponibilizar os códigos-fonte, notebooks, procedimentos de tratamento dos dados e resultados experimentais desenvolvidos durante a pesquisa.

Os materiais serão adicionados progressivamente, acompanhando o desenvolvimento do projeto.
